# MotionClue v1.0.0 — First Stable Release

MotionClue brings real-time vehicle motion cues to any Android phone (Android 8.0+), helping passengers reduce motion sickness (*kinetosis*) when using screens on the road.

---

### 🚀 Highlights

- **Dedicated Native C++17 Engine:** Sensor processing runs at 100 Hz on an isolated pthread with zero JVM garbage collection jitter.
- **Lock-Free State Sharing:** 120-byte payload transferred to the Kotlin UI via a seqlock Direct ByteBuffer.
- **Physical Spring-Damped Model:** 2nd-order critically damped physics calibrated to cornering, braking, and road curves.
- **GPS Speed Flow Mode:** Dots gently stream along screen margins proportional to actual vehicular speed.
- **100% Offline & Private:** Zero network permissions. No analytics, no tracking, no ads.

---

### ✨ What's New in v1.0.0

- **Transport Presets:** One-tap tuning for **Car**, **Bus / Metro**, **High-Speed Train**, and **Boat / Ferry**.
- **Walking Detection Auto-Pause:** Step detector and energy gating halt cues on foot.
- **Pocket Auto-Hide:** Proximity sensor turns off overlay when placed in a pocket or bag.
- **Adaptive Brightness:** Dots dim in darkness and brighten under direct sunlight using the ambient light sensor.
- **Material You Dynamic Colors:** Seamlessly matches your system theme on Android 12+.
- **Quick Settings Tile:** One-tap overlay toggle from anywhere.
- **Display Rotation Aware:** Real-time coordinate transformation across portrait and landscape orientations.

---

### 📱 Compatibility

- **Minimum:** Android 8.0 Oreo (API 26)
- **Target:** Android 16 (API 36)
- **Architectures:** `arm64-v8a`, `armeabi-v7a`, `x86_64`
