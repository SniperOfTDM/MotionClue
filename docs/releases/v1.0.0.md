# MotionClue v1.0.0 — Production Release

MotionClue brings real-time vehicle motion cues to Android handsets running Android 8.0 or newer (API 26+), mitigating passenger motion sickness through peripheral visual cues.

---

### Highlights

- **Dedicated Native C++17 Engine**: Sensor processing executes at 100 Hz on an isolated POSIX thread, eliminating JVM garbage collection pauses.
- **Lock-Free State Sharing**: 128-byte frame payload published via a seqlock Direct ByteBuffer.
- **Damped Spring Dynamics**: Second-order critically damped harmonic oscillator calibrated to vehicle braking, cornering, and acceleration.
- **Speed Flow Integration**: Continuous edge marker streaming proportional to ground speed.
- **Offline Operation**: Completely free of network permissions. No telemetry, analytics, or background reporting.

---

### Key Capabilities

- **Transport Profiles**: Calibrated presets for Automobile, Bus/Transit, Rail, and Marine travel.
- **Walking Auto-Pause**: Hardware step detection and kinetic energy gating suspend processing on foot.
- **Pocket Auto-Hide**: Proximity sensor halts overlay draw passes when stored in a pocket or bag.
- **Ambient Adaptation**: Light sensor dynamically scales marker luminance to match surrounding lux levels.
- **Material You Dynamic Colors**: System theme color matching on Android 12+.
- **Quick Settings Tile**: Fast single-tap overlay toggle.
- **Display Rotation**: Seamless coordinate transformation across portrait and landscape orientations.

---

### Compatibility

- **Minimum SDK**: Android 8.0 Oreo (API 26)
- **Target SDK**: Android 16 (API 36)
- **Supported ABIs**: `arm64-v8a`, `armeabi-v7a`, `x86_64`
